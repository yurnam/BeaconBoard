🧪 Simulation Mode

ℹ️ About Simulation Mode

Simulation mode creates 3 virtual test stations and 4 moving mock devices to test the system without physical hardware. The test stations register automatically but need to be positioned manually on the map (just like real stations). Once positioned, they send realistic mock RSSI observations every 2 seconds. Enable this mode to test triangulation, map visualization, and live tracking features before deploying real Raspberry Pi stations.

      How to Use

      1. Start Simulation: Click "Start Simulation" to create and register 3 test stations and 4 mock devices
      2. Position Stations: Go to the Map page - test stations will appear as purple pulsing circles
      3. Drag & Drop: Use "Edit Station Positions" to drag the test stations to desired locations on your floor plan
      4. Watch Live Tracking: Once positioned, mock devices will move around and be tracked via triangulation in real-time
      5. Test Features: Customize device names/icons on the Devices page, test webhooks, etc.
      6. Stop When Ready: Click "Stop Simulation" when your real Raspberry Pi stations are ready
      💡 Tip: Test stations start unpositioned (purple pulsing circles). Position them anywhere on your map to create different triangulation scenarios. Move them around to see how device positions change based on station placement! All simulated MACs start with "SIM:" prefix and won't interfere with real stations.
